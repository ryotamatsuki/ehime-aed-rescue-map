# えひめAEDレスキューマップ v1.0 使い方

公開URL: https://ryotamatsuki.github.io/ehime-aed-rescue-map/

## このアプリで分かること

このアプリは、AEDの位置を表示するだけの地図ではありません。松山市の100m人口メッシュとOpenStreetMapの歩行可能道路ネットワークを重ね、設定した短時間アクセス距離内でAEDに到達できる人口を推計し、さらに「AEDを1台追加するなら、どの公共施設に置くと未カバー人口を最も減らせるか」を計算します。

## 基本的な操作

1. 公開ページを開きます。
2. 「短時間アクセス距離」のスライダーで80〜640mの範囲を選びます。初期値は320mです。
3. 「全AED」または「24時間利用可のみ」を選びます。
4. 上部の主要指標で、カバー率、未カバー人口、75歳以上の未カバー人口、次の1台による改善幅を確認します。
5. 地図上では、AED、未カバーの100m人口メッシュ、推薦候補を確認できます。
6. 「次の1台を再計算」を押すと、現在の距離条件・AEDモードに応じて配置候補を再評価します。
7. 「推薦地点へ移動」を押すと、最も追加カバー人口が大きい候補施設へ地図が移動します。

## 指標の読み方

### 推計カバー率

100m人口メッシュ中心から歩行可能道路へ接続し、道路ネットワーク上の最短距離とAED側の接続距離を加えた距離が、設定値以内に収まる人口の割合です。

初期値320mは、歩行速度4.8km/hとした場合の片道約4分に相当します。これは政策・配置検討用のシナリオ値であり、医学的な救命時間の基準を示すものではありません。

### 推計未カバー人口

設定したネットワーク距離以内に対象AEDが存在しない100m人口メッシュの人口合計です。

### 75歳以上・未カバー

100m人口メッシュに含まれる `Pop75over` を使い、高齢人口の空間的な取り残され方を確認する指標です。

### 次の1台

既存AEDから一定距離以上離れた松山市の公共施設を候補にし、現在未カバーの100m人口メッシュを最も多く新たにカバーできる施設を選びます。同数の場合は75歳以上人口の改善幅を優先します。

## 「全AED」と「24時間利用可のみ」の違い

- **全AED**: 松山市公開データに掲載されたAEDを対象にします。施設の開館時間などにより、実際にはいつでも利用できるとは限りません。
- **24時間利用可のみ**: 公開CSVの利用可能曜日・時間・特記事項から「いつでも使用可」等を保守的に判定したAEDだけを対象にします。

24時間判定は公開データからの機械判定であり、現地の運用状況を保証するものではありません。

## データと分析条件

- AED: 松山市「AED設置箇所一覧」
- 人口: 2020年簡易100mメッシュ人口。国勢調査250mメッシュ人口を建物面積等で100mへ按分した推計データ
- 75歳以上人口: 100mメッシュの `Pop75over`
- 配置候補: 松山市「公共施設一覧」
- 歩行道路: OpenStreetMap
- 距離: メッシュ中心→最寄道路へのsnap距離 + 道路ネットワーク最短距離 + AED→道路へのsnap距離
- デフォルト閾値: 320m
- 想定歩行速度: 4.8km/h
- 対象道路から除外: motorway、motorway_link、construction、proposed、raceway、`foot=no`、`access=no/private` 等

## 注意事項

このアプリはオープンデータを利用した政策検討・配置検討用PoCです。救命時の行動判断を支援する医療機器検索サービスではありません。

以下は考慮していません。

- 建物内部でAEDを取り出す時間
- 信号待ち、横断歩道、階段、坂道、工事などによる歩行速度差
- AEDが実際に使用可能かどうかのリアルタイム状態
- 昼間人口、観光客、学校・事業所人口などの時間帯別人口
- AED取得後に傷病者へ戻る往復時間
- 施設側の設置可否、費用、電源、防犯、維持管理条件

緊急時は119番通報および消防・医療機関等の指示に従ってください。

## 再現・検証

データ生成は `python scripts/update_data.py`、分析QAは `python scripts/qa.py`、テストは `python -m unittest discover -s tests -v` で実行できます。GitHub Actionsでは公開データとOSMを実取得し、同じ分析パイプラインを検証したうえでGitHub Pagesへdeployします。
