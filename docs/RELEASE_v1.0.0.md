# v1.0.0 Release Notes

## Ehime AED Rescue Map v1.0.0

松山市のAED短時間アクセスを、**簡易100m人口メッシュ × OpenStreetMap歩行ネットワーク**で評価し、未カバー人口を減らす「次の1台」の配置候補を提示する公開WebGIS PoCの初回安定版です。

## v1.0.0 で固定する分析モデル

- 対象地域: 愛媛県松山市
- AED: 松山市「AED設置箇所一覧」671件
- 24時間利用可AED: 公開CSVから保守的に機械判定した74件
- 人口需要: 2020年簡易100mメッシュ人口
- 人口あり需要点: 12,535メッシュ
- 75歳以上人口: `Pop75over` を直接使用
- 歩行道路: OpenStreetMap
- 歩行ネットワーク: 375,621ノード / 801,118有向辺
- AEDの道路snap: 671 / 671件
- 24時間AEDの道路snap: 74 / 74件
- 人口メッシュの道路snap: 12,535 / 12,535件
- snap不能人口: 0人
- 配置候補: 松山市公共施設513地点
- 距離定義: メッシュ中心→道路snap + 道路最短経路 + AED→道路snap
- デフォルト短時間アクセス距離: 320m
- 想定歩行速度: 4.8km/h
- 320mの意味: 片道約4分相当の政策検討シナリオ。医学的基準ではない
- UI可変範囲: 80〜640m

## v0 PoCからの主要変更

初期PoCの「44地域人口を公共施設位置へ均等配分 + 直線距離」モデルを廃止しました。v1.0.0では、12,535個の100m人口メッシュを直接需要点にし、道路ネットワーク最短距離でカバレッジと配置候補を評価します。

このため、旧モデルの300m全AEDカバー率約69.9%から、v1.0.0の320m全AEDカバー率30.59%へ大きく変化しています。これは人口を公共施設へ人工的に集中させる処理と直線距離近似を除去した結果です。

## データ上の注意

簡易100mメッシュは、2020年国勢調査250mメッシュ人口を建物面積等で100mへ按分した推計データです。100m単位の国勢調査実測値ではありません。また、2026年の地域人口へ機械的に総数補正せず、2020年の空間分布をそのまま使用しています。

## 利用上の注意

本アプリは政策検討・オープンデータ活用PoCです。救命時の医学的判断やリアルタイムAED検索を目的とするものではありません。建物内取得時間、往復時間、信号待ち、坂道、リアルタイム稼働状況、時間帯別人口等はv1.0.0ではモデル化していません。

使い方は `docs/USAGE.md` を参照してください。
